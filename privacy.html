Rodney Agent privacy policy

Last updated: October 2, 2026

Rodney Agent is a private assistant used by a single person, Rodney. This policy covers the Google data it accesses.

What it accesses

When Rodney signs in with Google and grants access, the assistant can read his Gmail messages and attachments, create drafts and send emails he has approved, and read and change events on his Google Calendar that he has approved.

How the data is used

Only to assist Rodney: summaries, briefings, drafts, scheduling and reminders he asks for. The data is not used for advertising, is not sold, and is not shared with anyone else. It is not used to train general-purpose AI models.

To produce its answers, the assistant sends the content it is working on to Anthropic's Claude API for processing. Nothing else is shared with any third party.

Storage and security

Access tokens and working notes are kept on a private server used only for this assistant, readable only by the assistant's own account. Email and calendar content is read on demand and is not copied into a separate database.

Your control

Rodney can revoke access at any time at myaccount.google.com/permissions. When access is revoked, the stored tokens stop working and are deleted.

Google API Services User Data Policy

Rodney Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
